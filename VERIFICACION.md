# Verificación

Pasaron 11 pruebas automáticas de Python: contrato de los 12 campos, validación,
guardado con fecha y hora, persistencia, filtros por UMA, consultas individuales,
HTML y generación PNG con y sin datos. Se inspeccionó visualmente la gráfica.

Las pruebas Python se ejecutaron con Python 3.12. La guía propone Python 3.13.
El código Pascal se revisó con Free Pascal 3.2.2 y unidades Lazarus 3.0 en Linux.
La interfaz visual, compilación Windows y comunicación mediante VSPE deben
comprobarse en el computador de entrega siguiendo LEEME_PRIMERO.md.

No se incluyen ejecutables, entornos virtuales ni bases con datos de prueba.
